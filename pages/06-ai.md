# Case Study: Bun

The JavaScript runtime, rewritten from Zig to Rust in May 2026.

::left::

### Why

Some of the bugs fixed in a single release:

- use-after-free crash in `node:zlib`
- double-free crash in the CSS parser
- memory leak in `crypto.scrypt`
- a passphrase leaked on error paths

::right::

### How

- **535,496** lines of Zig, ported by Claude
- Then about **16,000** compiler errors
- `cargo check` became a **work queue**: per crate, 1 agent fixes and 2 more review
- **11 days**, 6,778 commits, about **$165k** of tokens
- **100%** of ~60,000 tests passing, none skipped or deleted

# Using Rust Doesn't Make Vibe Coding Safe

- `.unwrap()` everywhere (remember Cloudflare)
- `.clone()` just to keep the borrow checker quiet
- `unsafe` added into code without asking
- Logic bugs: well-typed code that does the wrong thing

# My Setup: GAVMO

George's Agent Virtual Machine Orchestrator

- Boots a disposable **NixOS VM** per repo, and runs the coding agent inside it
- The agent can only write to the repo: no `sudo`, no access to the rest of my machine
- API keys stay on the host, and the agent calls tools through a gateway
- Control panel written in **Leptos**
- Around 27k lines
- 90% test coverage

# Make The Compiler Aggressive

::left::

```toml
# GAVMO's Cargo.toml (trimmed)
[workspace.lints.rust]
unsafe_code = "deny"
unused_must_use = "deny"

[workspace.lints.clippy]
unwrap_used = "warn"
expect_used = "warn"
panic = "warn"
todo = "warn"
indexing_slicing = "warn"
allow_attributes_without_reason = "warn"
```

::right::

- CI runs clippy with `-D warnings`, so any warning blocks the build
- Turning a lint off needs a reason someone can review:
  ```rust
  #[expect(
      clippy::similar_names,
      reason = "uid/gid are the conventional names"
  )]
  ```
